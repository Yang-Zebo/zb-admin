## 三、模块需求详情

### 模块一：认证与授权

#### 3.1.1 登录

| 需求编号 | 需求描述 | 优先级 |
|:---:|------|:---:|
| LOGIN-001 | 用户输入**用户名 + 密码 + 验证码**登录 | P0 |
| LOGIN-002 | 后端验证用户状态（启用/停用），停用账号禁止登录 | P0 |
| LOGIN-003 | 密码使用 bcryptjs 加密存储，验证时比对哈希值 | P0 |
| LOGIN-004 | 登录成功返回 **Access Token**（短期，30分钟）和 **Refresh Token**（长期，7天） | P0 |
| LOGIN-005 | Access Token 携带 userId、username 信息，用于后续请求身份识别 | P0 |
| LOGIN-006 | 登录失败（密码错误、验证码错误）返回明确错误提示 | P0 |
| LOGIN-007 | 连续登录失败 5 次，锁定账号 30 分钟 | P1 |
| LOGIN-008 | 登录成功后记录登录日志（IP、时间、设备） | P1 |

#### 3.1.2 退出登录

| 需求编号 | 需求描述 | 优先级 |
|:---:|------|:---:|
| LOGOUT-001 | 用户退出时，后端将 Access Token 加入 Redis 黑名单，防止被复用 | P0 |
| LOGOUT-002 | 前端清除 localStorage/sessionStorage 中的 Token，跳转登录页 | P0 |

#### 3.1.3 Token 刷新

| 需求编号 | 需求描述 | 优先级 |
|:---:|------|:---:|
| TOKEN-001 | Access Token 过期后，前端自动用 Refresh Token 换取新的 Access Token | P0 |
| TOKEN-002 | Refresh Token 过期则强制跳转登录页 | P0 |
| TOKEN-003 | Axios 拦截器实现无感刷新，用户在操作过程中不会感知到 Token 刷新 | P1 |

#### 3.1.4 请求鉴权

| 需求编号 | 需求描述 | 优先级 |
|:---:|------|:---:|
| AUTH-001 | 所有后端接口（除登录/验证码）必须携带有效 JWT Token | P0 |
| AUTH-002 | NestJS Guard 全局拦截，解析 Token 并挂载用户信息到 Request 上下文 | P0 |
| AUTH-003 | Token 在黑名单中则拒绝请求，返回 401 | P0 |

## 四、核心业务流程

### 4.1 RBAC 权限判断流程

```
请求到达
   │
   ▼
JWT Guard 解析 Token → 获取 userId
   │
   ▼
从 Redis 查用户权限缓存
   │
   ├─ 命中缓存 → 拿到权限列表
   │
   └─ 未命中 → 查数据库
                ├─ 通过 userId → user_role 表 → 得到角色列表
                ├─ 通过角色列表 → role_menu 表 → 得到菜单/按钮权限列表
                └─ 写入 Redis 缓存（1小时过期）
   │
   ▼
比对当前请求所需权限是否在权限列表中
   │
   ├─ 有权限 → 放行，执行业务逻辑
   └─ 无权限 → 返回 403 Forbidden
```

### 4.2 前端动态路由生成流程

```
用户登录成功
   │
   ▼
存储 Token，跳转首页
   │
   ▼
路由守卫 beforeEnter 触发
   │
   ▼
调用后端接口 /auth/permissions 获取该用户的菜单权限树
   │
   ▼
前端递归解析菜单树，生成 Vue Router 路由配置
   ├─ 目录类型 → 不生成路由，仅作为分组
   ├─ 菜单类型 → router.addRoute() 动态注册
   └─ 按钮类型 → 存储到 Pinia 权限列表，供 v-permission 指令使用
   │
   ▼
渲染侧边栏菜单（仅显示用户有权访问的菜单项）
```

## 七、总结一览

| 维度 | 内容 |
|------|------|
| **前端技术** | Vite 5 + Vue 3 + TS + Element Plus + Vue Router 4 + Pinia + Axios + SCSS |
| **后端技术** | Node.js 20 + NestJS 10 + TS + Prisma 5 + MySQL 8 + Redis 7 + JWT |
| **开发模块** | 认证授权（登录/退出/Token刷新）、用户管理、角色管理、菜单权限管理、部门管理、操作日志、字典管理 |
